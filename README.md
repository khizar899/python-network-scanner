
# Python Network Scanner and Port Analyzer

## About the Project

This project is an educational Python application designed to
explore basic computer networking and network security.

It aims to identify reachable hosts and analyze selected
TCP ports on authorized test systems.

## Project Objectives

- Understand basic computer networking concepts.
- Learn Python socket programming.
- Understand IP addresses and TCP ports.
- Identify open and closed ports.
- Generate simple network scan reports.

## Technologies

- Python
- TCP/IP
- Socket Programming
- Visual Studio Code
- Git and GitHub

## Planned Features

- Host reachability checking
- TCP port scanning
- Common port identification
- Scan result reporting

Currently in development.
